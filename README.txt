MEMORA — pages HTML séparées

Fichiers :
- index.html : accueil
- categories.html : catégories
- boutique.html : produits et filtres
- personnaliser.html : création de coffret
- panier.html : panier et étape de commande démo
- compte.html : formulaire de compte démo
- contact.html : contact
- apropos.html : présentation
- css/style.css : style partagé
- js/app.js : JavaScript partagé

Utilisation :
1. Décompressez le ZIP.
2. Gardez toute la structure des dossiers intacte.
3. Ouvrez index.html dans votre navigateur.
4. Tous les liens du menu ouvrent une page HTML distincte, pas une section de la page d'accueil.
5. Une connexion Internet est requise pour les photos hébergées sur Unsplash.

Important :
Le panier est stocké localement dans le navigateur. Les formulaires de compte, de contact, le chat et le paiement sont des démonstrations front-end. Il faut connecter un backend, une base de données, un service de messagerie et un prestataire de paiement sécurisé avant une mise en production. N'utilisez pas cette maquette pour recueillir des mots de passe ou des données bancaires réels.
